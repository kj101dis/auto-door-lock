This is an auto door locking mechanism using a rack-and-pinion setup; it works is that there is a wire connected to it and the side of my bed. When you flip the rocker switch one way, it turns the rack-and-pinion setup and either arms or disarms it. The rack is a modified version of GoBuilda; it is scaled up by 3, and then a 10 mm rod will go through it to give it the strength it needs to block a strong push 




In this, you will need a rocker switch, which is not in the BOM because I have my own, but it doesn't matter which u have as long as it is 6-pin
